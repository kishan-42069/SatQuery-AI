# Context & Instructions

Please follow these rules at ALL TIMES when interacting with this repository:

1. **Implementation Plans First**: Before building anything or implementing new features, make sure to create an implementation plan.
2. **Answer Questions First**: Whenever the user asks a question or asks a suggestion, instead of directly executing, answer the question or give choices when necessary.
3. **Walkthrough Plans**: Create a well-detailed walkthrough plan in the simplest words possible so that any user can understand it (even outside of their expertise).
4. **Double Review**: Make sure the user reviews the implementation plan and answers twice before going ahead with execution.
5. **Minimal Comments**: Keep the comments as minimal as possible and just give a one-liner about the project/function/file and what it does (max 2 lines).
6. **Utilize Skills & MCP**: Use the MCP and skills attached to the project whenever it is possible instead of ignoring them *IF IT IS RELEVANT!*
